# Площадки: где про них написано и как добавить новую

Справочник-указатель. Данных здесь нет — они живут в коде, и это намеренно:
второй список расходится с первым всегда. Здесь сказано, **какой реестр за что
отвечает**, чтобы не искать по всему сборщику.

Идея простая и повторяется во всех четырёх реестрах: **свойство площадки — это
данные, поведение — общий механизм**. Добавить площадку значит дописать строку в
нужный реестр, а не ветку `if host == …` в коде.

## Четыре реестра, и у каждого своя работа

| Реестр | Где | Отвечает за |
|---|---|---|
| `sources.SOURCES` | `sources.py` | что и как собирается **анонимно**: адрес API или страницы, окно, пагинация, потолки |
| `sources_auth.SOURCES_AUTH` | `sources_auth.py` | то же, но **под сессией**: shadowhint, wantapply, hh, careered |
| `sources_keyed.PLATFORMS` | `sources_keyed.py` | площадки с **бесплатным ключом**: где ключ взять, какие переменные нужны, как честно выключиться без него |
| `auth.PLATFORMS` | `auth.py` | **вход и сессия**: адрес логина, чем проверить живость, где лежит токен, что теряется без входа |

Плюс два маленьких: `detail._ATS_DETAIL` — разборщики ATS-досок, и
`channel._AGGREGATORS` / `_AGGREGATOR_NAMES` / `_NOT_EMPLOYER_NAMES` — кто
витрина, а кто работодатель (один список на проект, спрашивается через
`is_aggregator_domain`).

## Свойства сессии в `auth.PLATFORMS` — что они включают

| Ключ | Что означает | Кто читает |
|---|---|---|
| `login_url`, `check_url` | куда вести человека и чем проверять | `auth login`, `auth check` |
| `alive_if` / `dead_if` | маркеры залогиненности на странице | `auth check` |
| `session_cookie` | кука-носитель токена: `(домен, имя)` | `session_probe`, `adopt_session_cookie` |
| `state_cookie` | сессия лежит целым storage_state | `adopt_from_browser`, `renew_hirehi` |
| `login_gains` | **что именно теряется** без входа | `authrefresh.cost_of_death` |
| `login_optional` | без входа сбор всё равно идёт | там же |
| `cloudflare` | сайт под управляемым челленджем, робот туда не ходит | `auth`, `sources_auth` |
| `adopt_safe` | **токен мы не ротируем** → свежую куку можно забирать из браузера САМИМ, перед каждым прогоном | `authrefresh.adopt_safe_sessions`, зовётся из `wave` |

🔴 `adopt_safe` — не «у площадки есть кука», а «мы её не обмениваем». У hirehi
кука тоже есть, но обмен refresh-токена ротирует единственный креденшл и
разлогинивает живую вкладку владельца — поэтому флага там нет и не будет.

## Как добавить площадку

1. **Сбор.** Строка в `SOURCES` (аноним), `SOURCES_AUTH` (под сессией) или
   `sources_keyed.PLATFORMS` (с ключом). Обход, пагинация и потолки — параметрами,
   не кодом.
2. **Вход**, если нужен: строка в `auth.PLATFORMS`. Обязательно `login_gains` —
   без него `preflight` не сможет сказать, что теряется, и строку «залогинься»
   перестанут читать.
3. **Продление.** Ротации нет → поставь `adopt_safe: True`, и всё. Ротация есть →
   нужен свой продлеватель в `authrefresh.RENEWERS` (как `renew_hirehi`).
4. **Выжимка.** Если у площадки свой формат — ветка в `detail._dispatch`; если
   обычная страница — ничего не нужно, справится generic.
5. **Витрина или работодатель.** Витрину — в `channel._AGGREGATORS` (точный
   домен) или `_AGGREGATOR_NAMES` (имя без зоны, если у неё доска в каждой
   стране: adzuna.de, adzuna.pl, adzuna.co.uk).

## Правило про стены

Упёрлись в антибот — **ищите ручку, которой площадка кормит саму себя**:
встраиваемые карточки, мобильное приложение, публичный API. Она почти всегда
открыта, потому что её зовут с чужих сайтов. Проверено 09.08.2026:

- **LinkedIn** — `linkedin.com/jobs-guest/jobs/api/jobPosting/<id>` отдаёт полное
  описание и статус набора без входа, тогда как `/jobs/view/…` закрыт и для
  stdlib, и для браузера;
- **wantapply** — весь каталог на `api.wantapply.com`, сам сайт под Cloudflare;
- **adzuna** — описание приезжает прямо в ответе API, деталка не нужна.

Исключение тоже проверено: у **careerjet** закрыты все двери (трекер отдаёт 500,
браузер упирается в капчу, в API прямого адреса нет). Капчу не обходим — это
постоянное правило, а не сегодняшнее ограничение.
