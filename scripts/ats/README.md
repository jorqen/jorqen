# ATS-скрипты: поиск вакансий по доскам работодателей

Написаны и проверены живыми запросами 25.07.2026 в ходе скана `/jobs`.
Закрывают повторяющуюся задачу: **найти живые доски компаний и отфильтровать
вакансии по стране** — руками это десятки попыток с угадыванием токенов.

Реестр уже проверенных токенов и ловушек — в
`.claude/skills/jobs/references/sources-setup.md`, раздел «Реестр ATS-токенов».

## Что есть

| Скрипт | Задача |
|---|---|
| `check.sh` | проверка живости токена на всех шести ATS сразу |
| `tr2.sh` | структурный матчер локаций (Greenhouse, Ashby, Lever) — **умеет `secondaryLocations[]`** |
| `fin.sh` | подсчёт вакансий + сводка по стране, все шесть ATS |
| `hosts.sh`, `sniff.sh` | сниффер внешних хостов на careers-странице — вычисляет, на каком ATS сидит компания |
| `lv.sh`, `tr.sh`, `run*.sh` | обёртки под конкретные прогоны |

## Почему `tr2.sh` важнее остальных

Фильтр по одному полю `locationName` **пропускает вакансии**. Реальный случай:
у Ruby Labs 16 вакансий из 39 доступны из Турции, но страна лежит
в `secondaryLocations[]`, а не в основном поле. Greenhouse аналогично прячет
страну в `offices[]` или прямо в заголовке.

## Известные подводные камни

- **SmartRecruiters** отдаёт `HTTP 200` и `totalFound: 0` для несуществующих компаний.
  Ноль означает «доски нет», а не «вакансий нет».
- **Хоста `boards-api.eu.greenhouse.io` не существует** (NXDOMAIN) — европейские
  доски через JSON API недоступны, только `job-boards.eu.greenhouse.io` браузером.
- **Токены не угадываются.** `insider` на Greenhouse — это Business Insider, медиа
  из Нью-Йорка. `midas` на Lever не существует, нужен `getmidas`. Всегда сверяй
  название компании внутри ответа.
- **Живая доска с нулём вакансий — это не сбой.** Проверено на Workable: у Exness,
  SOAX, Papara доски существуют и пусты, потому что компании нанимают в другом месте.
